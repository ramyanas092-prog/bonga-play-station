# BONGA PLAY STATION — مشروع أندرويد أولي

## الموجود في هذه النسخة
- واجهة عربية لإدارة 4 أجهزة PS4 وجهاز PS5.
- مؤقتات بدء/إيقاف مؤقت/إنهاء الجلسة.
- أسعار افتراضية قابلة للتعديل: PS4 = 35 جنيه، PS5 = 45 جنيه.
- تسجيل مبيعات ومصروفات.
- تقارير يومية وشهرية.
- حفظ محلي ونسخة احتياطية JSON.

## حدود النسخة الحالية
- هذا مشروع مصدر Android Studio وليس ملف APK جاهزًا.
- أول مرة، ينشئ المستخدم الرقم السري على الجهاز؛ لذلك هذا ليس بعد نظام تفعيل مركزيًا يمنح المالك الموافقة عن بُعد.
- البيانات محلية على الجهاز، ولا يوجد مزامنة سحابية أو تفعيل عن بعد بعد.
- المبالغ في هذه النسخة تُحسب بالتقريب لأعلى إلى الساعة الكاملة عند إنهاء اللعب؛ عدّل المنطق قبل الاستخدام التجاري إذا أردت الحساب بالدقيقة أو بنظام آخر.
- اختبر المشروع في Android Studio قبل استخدامه فعليًا. قد تحتاج إلى تثبيت Android SDK 35 وGradle متوافق.

## البناء
افتح المجلد في Android Studio ثم اختر Build > Build APK(s).
